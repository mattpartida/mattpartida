# Matt Partida

Building tools for autonomous-agent security, prompt-injection defense, and research automation.

## Current focus

- **Agent security** — practical checklists, skillpacks, and controls for safer autonomous-agent deployments.
- **Prompt-injection defense** — config linting, behavioral benchmarks, and repeatable tests for tool misuse and data exfiltration risks.
- **Research automation** — local-first workflows for investing research, diligence notes, and signal discovery.
